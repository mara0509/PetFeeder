Smart Pet Feeder is an IoT-based automated feeding system designed to simplify pet feeding while providing real-time monitoring and remote control capabilities. The system is built around a Raspberry Pi 5 and an ESP32, with a load cell and HX711 amplifier used to monitor the amount of food available and a PIR HC-SR501 sensor used to detect the presence of the pet. It supports automatic feeding according to predefined schedules, manual and remote food dispensing, as well as pet-assisted feeding, where the system detects the pet near the feeder and allows the owner to approve feeding. The Raspberry Pi acts as the main edge gateway, collecting and processing sensor data and communicating with AWS IoT Core through MQTT 5 using TLS and X.509 certificate authentication, while the ESP32 controls the servo motor responsible for dispensing the food. A Flask backend, Firebase Realtime Database, and React-based web dashboard are used to provide remote monitoring, control, scheduling, and visualization of historical feeder data. The system also includes an AI-powered Nutrition Consultant, implemented as an intelligent agent based on a Large Language Model (LLM), which generates personalized feeding recommendations based on the pet’s species, breed, age, and weight. These recommendations are combined with the feeder’s sensor data to estimate the pet’s daily food consumption and provide an overfeeding warning when the measured intake exceeds the recommended amount. Overall, the project combines embedded systems, IoT communication, cloud services, web development, sensor-based monitoring, and AI into an integrated smart pet-care platform.
